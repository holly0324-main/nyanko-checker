# にゃんこ超激レア所持チェッカー v2.0.1（iPhone / PC 両対応）

コラボを除外した超激レアの所持状況を画像で管理する個人用PWAです。

## 普段の使い方
1. キャラ画像をタップ → 所持（カラー＋✓）/ 未所持（グレー）を切替
2. 「ガチャ / シリーズ」を選ぶと絞り込み
3. 「すべて / 所持 / 未所持」や名前・No.検索も利用可能
4. 所持状況は端末内に自動保存

誤操作で大量の所持状態が変わらないよう、**一括で全所持・全未所持にするボタンは置いていません**。

## バックアップ
⚙︎ →「バックアップを書き出す」→ iPhoneの共有メニューで「ファイルに保存」→ iCloud Driveを選択。
復元は「バックアップから復元」で、そのJSONを選ぶだけです。
PCへ移行するときも同じJSONを使えます。旧v1/v2系の `owned:true/false` 形式も読み込めます。

## iPhoneでホーム画面アプリにする
PWAとして使うにはHTTPSで公開する必要があります。GitHub Pagesにこのフォルダの中身を置くのが無料で簡単です。
詳しい手順は「iPhoneだけで導入する手順.md」を参照してください。

## 新キャラが追加されたら
「新キャラ追加時の更新手順.md」を参照してください。
**所持データはアプリ本体とは別に端末へ保存されるため、アプリファイルを更新しても通常は消えません。** 念のため更新前にJSONバックアップを取るのがおすすめです。

## データ
キャラデータ基準日: 2026-08-11  
画像: にゃんこ大戦争DBの第1形態画像をリモート参照。アプリ本体にはゲーム画像を同梱していません。

混成・選抜ガチャは排出プールが変動しやすいため、祭/バスターズは主に「限定キャラ」フィルターにしています。通常シリーズと主要季節ガチャはガチャ単位で絞れます。
