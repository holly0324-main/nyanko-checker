# にゃんこ超激レア所持チェッカー v2.1.0（iPhone / PC 両対応）

コラボを除外した超激レアの所持状況を画像で管理する個人用PWAです。

## v2.1.0の重要な変更
ガチャ絞り込みデータを全面監査しました。

以前は、キャラ側の `groups` とガチャ側の `ids` の二重管理や、「祭限定キャラだけ」のような近似分類が混在していたため、実際の排出プールとのズレが発生していました。

v2.1.0からは **`groups[].ids` に書かれた「そのガチャから実際に排出される超激レアID一覧」だけを唯一の判定元**にします。キャラ側には所属ガチャ情報を持たせません。

### 固定フィルタとして収録しているガチャ
- 通常シリーズ 11種
- 超ネコ祭 / 極ネコ祭 / 超極ネコ祭
- レッド / エア / メタル / 波動 / 超生命体バスターズ、バスターズ祭
- ハロウィン、クリスマス、サマー2種、イースター、バレンタイン、ホワイトデー、ジューンブライド

`超選抜祭`、`極選抜祭`、DL記念選抜、周年セレクションなど、**開催回ごとに排出プールそのものが変わるガチャは固定フィルタにしていません**。開催時に実際のラインナップを確認して必要なら追加します。

## 普段の使い方
1. キャラ画像をタップ → 所持（カラー＋✓）/ 未所持（グレー）を切替
2. 「ガチャ / シリーズ」を選ぶと、そのガチャの実際の超激レア排出プールだけに絞り込み
3. 「すべて / 所持 / 未所持」や名前・No.検索も利用可能
4. 所持状況は端末内に自動保存

誤操作防止のため、一括で全所持・全未所持にするボタンは置いていません。

## バックアップ
⚙︎ →「バックアップを書き出す」→ iPhoneの共有メニューで「ファイルに保存」→ iCloud Driveを選択。
復元は「バックアップから復元」で、そのJSONを選ぶだけです。PCへ移行するときも同じJSONを使えます。

## 新キャラが追加されたら
「新キャラ追加時の更新手順.md」を参照してください。
所持データはアプリ本体とは別に端末へ保存されるため、アプリ更新で通常は消えません。念のため更新前にJSONバックアップを取るのがおすすめです。
